# SPO1 — синтаксический анализ и AST

## Что реализовано
- Лексический анализ на Flex и синтаксический разбор на Bison для языка по варианту.
- Построение дерева разбора (AST) с явными узлами для всех конструкций.
- Обертка над парсером, возвращающая AST и коллекцию предупреждений.
- Экспорт AST в DGML для графического просмотра.

## Структура проекта
- `ast/lexer.l` — лексер (токены, позиции, сообщения об ошибках).
- `ast/parser.y` — грамматика Bison и построение AST.
- `ast/ast.h`, `ast/ast.c` — структуры AST и функции создания/освобождения узлов.
- `ast/ast_maker.h`, `ast/ast_maker.c` — интерфейс `create_ast_wrap()`.
- `view/dgml.h`, `view/dgml.c` — вывод AST в DGML.
- `main.c` — тестовая CLI-программа.

## Сборка
Нужны `flex`, `bison` и компилятор C (gcc/clang).

```bash
make -C SPO1 build
```

## Запуск
```bash
./SPO1/app <input_files...> <output_dir>
```

Пример:
```bash
./SPO1/app ./SPO1/tests/input.txt ./SPO1/results
```

## Выходные файлы
Для каждого входного файла создается DGML:
- `ast.<source_name>.dgml`

Ошибки лексера/парсера выводятся в `stderr` с координатами строки/столбца.

## Примеры
- Входные тесты: `SPO1/tests/input.txt`
- Рекомендуемая директория вывода: `SPO1/results`

## Примечания
- Для Windows можно использовать проект Visual Studio: `SPO1/SPO.vcxproj`.
